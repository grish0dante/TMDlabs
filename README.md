# ToDoList - програма «Список справ»

## Мета: 
Розробити програму для ведення списку справ, яка зберігає завдання у вбудованій базі даних SQLite.

## Особливості:
* Опис завдання з вказівкою планованої дати та часу виконання (початок - кінець) на окремій активності.
* Додавання, оновлення та видалення завдань до списку завдань на окремій активності.
* Позначити завдання як виконані в обох активностях.
* Передбачити для списку завдань фільтрацію за датами та статусом виконання.
